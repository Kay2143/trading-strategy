# 주식천재stock-research-agent

한국 주식 리서치 전담 에이전트의 별도 작업 공간입니다.

이 에이전트는 현재 다음 범위만 담당합니다.

- 시장 및 종목 자료 학습
- 종목별 분석 보고서 작성
- 전략 아이디어의 백테스트
- 시대별 검증과 과적합 점검
- 리스크와 반대 근거 정리
- 텔레그램 발송 전 검토 자료 생성

이 공간의 모든 산출물은 매매 추천이 아닌 의사결정 지원 자료입니다.
실제 주식 거래를 에이전트가 자동 실행하는 기능은 포함하지 않습니다.
분석을 시작할 때 관련 `knowledge/` 문서와 `sources/`의 출처·한계를 먼저 확인합니다.

워크플로 변경이 기본 브랜치에 반영되면 정기 분석이 GitHub Actions에서 평일 오전 8시(KST)에 실행됩니다. 엄격한 기술적 기준을 통과한 후보가 있을 때만 텔레그램으로 보내고, 일일 보고서와 5거래일 성과 기록을 이 폴더에 누적합니다. 모델 재학습이나 자동 매매는 하지 않습니다.

저장소가 공개 상태이므로, 여기에 커밋되는 후보 보고서와 성과 기록도 공개됩니다.

## 폴더 구조

- `knowledge/`: 시장 지식과 전략 메모
- `sources/`: 데이터 출처와 수집 메타데이터
- `research/`: 종목별 분석 보고서
- `backtests/`: 백테스트 설정과 결과
- `decisions/`: 판단 기록과 사후 검증
- `reports/`: 일간/주간 요약
- `logs/`: 실행 이력

## 설계 문서

- `DESIGN.md`: 분석 파이프라인과 단계별 운영 구조
- `QUALITY-GATES.md`: 자동 발송 및 매매 승인 차단 조건
- `ROADMAP.md`: 학습부터 수동 승인, 자동매매까지의 단계
- `knowledge/종목발굴-방법론.md`: 사용자가 제공한 투자 자료에서 정리한 후보 발굴 방법
- `sources/Investment-PDF.md`: 원본 PDF의 출처 정보와 적용 한계
