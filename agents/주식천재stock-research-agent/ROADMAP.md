# Roadmap

## 1단계: 자료 기반 전환

- 기존 단순 스크리너와 분리
- 공식 또는 공개 가능 데이터만 사용
- 출처 메타데이터와 조회 시점 기록
- 종목별 근거와 반대 근거 템플릿 추가
- 일일 기술 분석과 후보별 5거래일 코스피 초과수익 기록
- 기본 가격 데이터만으로 판단할 수 없는 재무·공시 항목은 미평가로 명시

## 2단계: 백테스트 재설계

- 공식 OpenDART API 등 사용이 허가된 재무 데이터 공급원 연결 후 진행
- 기존 전략의 재현성 검증
- 기준선과 시대별 성과 비교
- 거래 비용과 슬리피지 반영
- 데이터 누수와 생존 편향 점검

## 3단계: 텔레그램 품질 개선

- 품질 게이트 통과 후보만 발송
- 후보 없음과 유의미한 후보를 구분
- 중복 발송 차단
- 검증 요약과 위험 요약 포함

## 4단계: 모의 매매

- 가상 계좌와 체결 지연 모델
- 일일 손실 한도와 포지션 한도
- 진입, 손절, 청산 로그
- 실거래 전 최소 운영 기간 확보

## 5단계: 수동 승인 매매

- 에이전트는 주문 초안만 생성
- 사용자가 가격과 수량을 확인해 승인
- 체결 및 사후 추적 기록
- 주문 실패와 부분 체결 처리

## 6단계: 제한적 자동매매

- 사전 승인된 종목군과 전략만 허용
- 일일 손실 한도 강제
- 예상치 못한 가격과 데이터에 대한 긴급 정지
- 사용자 동의가 갱신될 때까지 제한 유지
