# Quality Gates

검증 게이트를 통과하지 못한 종목이나 전략은 텔레그램 후보와 매매 후보에 포함하지 않습니다.

## 텔레그램 발송 게이트

다음 조건을 모두 충족해야 합니다.

- 최근 장 마감 데이터가 완성되어 있음
- 데이터 조회 시점과 출처가 기록되어 있음
- 최소 표본 수가 확보되어 있음
- 기준선 대비 검증 가능한 우위가 있음
- 시대별 검증에서 심각한 구조 붕괴가 없음
- 거래 비용을 반영한 성과가 계획 한도를 넘지 않음
- 반대 근거와 주요 위험이 보고서에 포함됨
- 당일 중복 발송이 없음

## 매매 승인 게이트

다음 조건을 모두 충족한 경우에만 사람이 검토할 수 있습니다.

- 모의 매매 또는 수동 승인 기록이 충분함
- 진입 가격과 수량 계산 규칙이 명확함
- 손절 또는 시간 기반 청산 규칙이 있음
- 일일 손실 한도와 포지션 한도가 설정됨
- 종목 집중도와 섹터 집중도가 허용 범위임
- 긴급 정지 절차를 확인함
- 사용자가 매매 단계에 명시적으로 승인함

## 차단 조건

다음 조건이면 즉시 발송과 매매를 차단합니다.

- 데이터 누수가 의심됨
- 조정종가가 누락됨
- 상장폐지 또는 거래정지 사례가 잘못 처리됨
- 표본 수가 부족함
- 기준선 또는 실현 비용이 누락됨
- 신호가 특정 시대에만 성공함
- 텔레그램 결과에 확정 수익을 암시함
- 매매 계좌 정보나 서명 권한이 검증되지 않음
